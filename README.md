# pishi

Скилл и плагин для редактуры текстов по принципам книги М. Ильяхова и Л. Сарычевой «Пиши, сокращай».
Убирает стоп-слова, канцелярит, штампы и пустые оценки, заменяет их фактами, упрощает синтаксис
и выстраивает структуру вокруг пользы читателя. Работает в Claude Code, claude.ai, ChatGPT и Codex.

## Как устроено

Правила живут в одной папке — `skills/pishi/`. Все платформы читают её.

- `SKILL.md` — основа: три вопроса к каждому фрагменту (польза, честность, забота), четыре режима
  (редактура, разбор с комментариями, написание с нуля, сокращение до объёма), порядок правки сверху вниз
  (смысл → структура → факты → предложения → слова), чеклист и формат ответа.
- `references/stop-words.md` — 15 категорий стоп-слов: чем заменить и когда слово стоит оставить.
- `references/syntax.md` — правила для предложений: отглагольные существительные, пассив, цепочки родительного падежа, обороты.
- `references/genres.md` — структура по жанрам: письмо, КП, лендинг, пост, рассылка, инструкция, вакансия, ответ клиенту, новость.
- `references/english.md` — аналоги категорий для английских текстов.
- `scripts/scan.py` — подсвечивает кандидатов в стоп-слова, длинные предложения, пассив и скопления отглагольных существительных.

Только в Claude Code есть ещё агент-редактор (`agents/editor.md`) и команда `/pishi:redakt` (`commands/redakt.md`).

## Ограничения, заложенные специально

- **Никаких выдуманных фактов.** Если убрать «качественный», а подтверждения нет, ставится плейсхолдер
  `[нужен факт: …]`, а не правдоподобная цифра.
- **Голос автора в эссе и постах сохраняется:** убирается мусор, а не стиль.
- **В договорах и ТЗ канцелярит не трогается молча:** он бывает точным термином.

## Оговорки

- Принципы пересказаны своими словами, текст книги не цитируется.
- Английская часть — адаптация, в книге её нет.
- Сканер работает на регулярных выражениях без морфологии и даёт ложные срабатывания. Это подсказка, вердикт выносит модель по смыслу.

## Установка

| Платформа | Что ставится | Статус |
|---|---|---|
| Claude Code | плагин: скилл, агент, команда | проверено |
| Codex CLI | скилл из плагина | проверено |
| claude.ai | скилл (загрузка zip) | не проверено |
| ChatGPT веб и мобильный | скилл (загрузка zip) | не проверено |
| ChatGPT десктоп | скилл из плагина | не проверено |

**Claude Code**

```
/plugin marketplace add Kir-STR/pishi
/plugin install pishi@pishi
```

Из локальной копии репо — из родительской папки: `/plugin marketplace add ./pishi`.

**Codex CLI**

```
codex plugin marketplace add Kir-STR/pishi
codex plugin add pishi@pishi
```

Из локальной копии: `codex plugin marketplace add <путь к репо>`. Отдельный манифест для Codex не нужен:
он читает `.claude-plugin/marketplace.json`.

**claude.ai и ChatGPT (веб, мобильный)**

1. Собрать архив: `pwsh ./build.ps1` (нужен PowerShell 7) → `dist/pishi.zip`.
2. claude.ai: Customize → Skills → загрузить zip. Скиллам нужна настройка Settings → Capabilities →
   «Code execution and file creation»; обычно она включена по умолчанию.
3. ChatGPT: Skills → New skill → Upload from your computer → zip. Если раздела Skills нет (зависит от тарифа),
   можно загрузить файлы из `skills/pishi/` в Project — этот путь не проверен.

**ChatGPT десктоп — не проверено.** По [документации OpenAI](https://developers.openai.com/plugins/build/plugins)
локальные marketplace появляются в Plugins Directory в режимах Work и Codex: добавить marketplace так же, как для Codex CLI,
перезапустить приложение и установить `pishi` из Plugins Directory.

Не держите копию скилла в `~/.claude/skills/` или `~/.codex/skills/` рядом с плагином — платформа увидит два одинаковых скилла.

## Использование

- **Claude Code:** `/pishi:redakt <путь к файлу>` (файл в UTF-8). Агент-редактор разбирает файл и предлагает правки
  в формате «фрагмент → проблема → замена», не применяя их. Можно и просто попросить отредактировать текст — скилл подхватится сам.
- **Остальные платформы:** попросите отредактировать, сократить или разобрать текст; скилл подхватывается по описанию.
- **Сканер отдельно:** `python skills/pishi/scripts/scan.py file.txt [--json]`. На вход — UTF-8;
  в Windows PowerShell 5.1 передавайте путь к файлу, а не pipe.

## Обновление после правки скилла

> **Внимание:** платформы обновляются по-разному.

- **Claude Code, marketplace из локальной папки** — плагин читается прямо из репо: новая сессия или `/reload-plugins`.
- **Claude Code, marketplace из GitHub** — `claude plugin update pishi@pishi`, затем `/reload-plugins`.
- **Codex CLI** копирует плагин при установке: повторите `codex plugin add pishi@pishi`;
  для marketplace из GitHub перед этим — `codex plugin marketplace upgrade pishi`.
- **ChatGPT десктоп** — способ обновления не проверен.
- **claude.ai и ChatGPT веб** — `pwsh ./build.ps1` и перезалить zip.

Установка и обновление из GitHub проверены на чистых настройках Claude Code и Codex CLI.
