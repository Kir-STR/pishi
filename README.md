# pishi

Скилл и плагин для редактуры текстов по принципам книги М. Ильяхова и Л. Сарычевой «Пиши, сокращай».
Убирает стоп-слова, канцелярит и штампы. Пустые оценки заменяет фактами, а если фактов нет, ставит пометку
`[нужен факт: …]`. Упрощает синтаксис и выстраивает структуру вокруг пользы читателя.
Работает в Claude Code, Claudian (Obsidian), claude.ai, ChatGPT и Codex.

Сайт: [kir-str.github.io/pishi](https://kir-str.github.io/pishi/)

**Пример:**

- «Стоит отметить, что доставка бесплатная» → «Доставка бесплатная».
- «Высококачественный сервис», а подтверждения нет → «Сервис» и пометка
  `[нужен факт: чем подтверждается качество — гарантия, сертификат, процент возвратов?]`.

## Установка

| Платформа | Что ставится |
|---|---|
| Claude Code | плагин: скилл, агент, команда |
| Claudian (Obsidian) | плагин из Claude Code |
| Codex CLI | скилл из плагина |
| claude.ai | скилл (загрузка zip) |
| ChatGPT веб и мобильный | скилл (загрузка zip) |
| ChatGPT десктоп | скилл из плагина |

Установка проверена на всех платформах из таблицы. Установка и обновление из GitHub проверены
на чистых настройках Claude Code и Codex CLI.

**Claude Code**

```
/plugin marketplace add Kir-STR/pishi
/plugin install pishi@pishi
```

Из локальной копии: в папке, где лежит `pishi/`, выполните `/plugin marketplace add ./pishi`.

**Claudian (Obsidian)** берёт плагины из `~/.claude/plugins`: поставьте плагин один раз в Claude Code.

**Codex CLI**

```
codex plugin marketplace add Kir-STR/pishi
codex plugin add pishi@pishi
```

Из локальной копии: `codex plugin marketplace add <путь к репо>`.

**ChatGPT десктоп.** Добавьте marketplace так же, как для Codex CLI, и перезапустите приложение.
Marketplace появится в Plugins Directory в режимах Work и Codex
([документация OpenAI](https://developers.openai.com/plugins/build/plugins)), установите оттуда `pishi`.

**claude.ai и ChatGPT (веб, мобильный)**

1. Скачайте [pishi.zip](https://github.com/Kir-STR/pishi/releases/latest/download/pishi.zip) из последнего релиза.
   Или соберите сами: `pwsh ./build.ps1` (нужен PowerShell 7) → `dist/pishi.zip`.
2. Загрузите zip:
   - **claude.ai:** проверьте, что включено Settings → Capabilities → «Code execution and file creation»
     (обычно включено по умолчанию), затем Customize → Skills → загрузите zip.
   - **ChatGPT:** Skills → New skill → Upload from your computer → zip. Если раздела Skills нет (зависит от тарифа),
     загрузите файлы из `skills/pishi/` в Project — этот путь не проверен.

**Если платформа видит две копии скилла**

- Не держите копию скилла в `~/.claude/skills/` или `~/.codex/skills/` рядом с плагином.
- Если скилл загружен в claude.ai и плагин стоит в Claude Code, Claude Code подтягивает скиллы из аккаунта claude.ai
  (`anthropic-skills:pishi`) и видит две копии. Отключите копию из claude.ai в `~/.claude/settings.json` —
  скилл плагина это не затрагивает:

  ```json
  "skillOverrides": { "anthropic-skills:pishi": "off" }
  ```

## Использование

- **Любая платформа:** попросите отредактировать, сократить или разобрать текст — скилл подключится сам.
- **Claude Code, разбор файла:** `/pishi:redakt <путь к файлу>` (файл в UTF-8). Агент-редактор разбирает файл
  и предлагает правки в формате «фрагмент → проблема → замена», не применяя их.
- **Сканер отдельно:** `python skills/pishi/scripts/scan.py file.txt [--json]` — ищет только в русском тексте.
  На вход — UTF-8; в Windows PowerShell 5.1 передавайте путь к файлу, а не pipe.

## Обновление: у каждой платформы свой способ

- **Claude Code, marketplace из локальной папки:** Claude Code читает плагин прямо из репо —
  откройте новую сессию или выполните `/reload-plugins`.
- **Claude Code, marketplace из GitHub:** выполните `claude plugin update pishi@pishi`, затем `/reload-plugins`.
- **Codex CLI** копирует плагин при установке: повторите `codex plugin add pishi@pishi`;
  для marketplace из GitHub перед этим выполните `codex plugin marketplace upgrade pishi`.
- **ChatGPT десктоп:** способ обновления не проверен.
- **claude.ai и ChatGPT:** скачайте новый zip из [последнего релиза](https://github.com/Kir-STR/pishi/releases/latest),
  удалите старый скилл и загрузите новый.

## Чего скилл не делает

- **Не выдумывает факты.** Если скилл убрал «качественный», а подтверждения нет, он ставит пометку
  `[нужен факт: …]`, а не правдоподобную цифру.
- **Не стирает голос автора.** В эссе и постах убирает мусор, а не стиль.
- **Не правит договоры и ТЗ молча.** Канцелярит там бывает точным термином, поэтому скилл предлагает упрощение
  и помечает места, где замена может изменить юридический смысл.

## Оговорки

- Принципы пересказаны своими словами, текст книги не цитируется.
- Английская часть — адаптация, в книге её нет.
- Сканер работает на регулярных выражениях без морфологии и даёт ложные срабатывания. Это подсказка,
  вердикт выносит модель по смыслу.
- Скилл не привязан к модели: проверен с моделями Claude, с MiMo в Claude Code и с моделями OpenAI в Codex CLI
  и ChatGPT. Скилл написан в открытом формате [Agent Skills](https://agentskills.io), поэтому должен работать
  и в других агентах с его поддержкой, но это не проверено.

## Как устроено

Правила живут в одной папке — `skills/pishi/`. Все платформы читают её.

- `SKILL.md` — основа. Три вопроса к каждому фрагменту: польза, честность, забота. Четыре режима: редактура,
  разбор с комментариями, написание с нуля, сокращение до объёма. Порядок правки от крупного к мелкому:
  смысл → структура → факты → предложения → слова. Чеклист и формат ответа.
- `references/stop-words.md` — 15 категорий стоп-слов: чем заменить и когда слово стоит оставить.
- `references/syntax.md` — правила для предложений: отглагольные существительные, пассив, цепочки родительного падежа, обороты.
- `references/genres.md` — структура по жанрам: письмо, КП, лендинг, пост, рассылка, инструкция, вакансия, ответ клиенту, новость.
- `references/english.md` — аналоги категорий для английских текстов.
- `scripts/scan.py` — в русском тексте подсвечивает кандидатов в стоп-слова, длинные предложения, пассив
  и скопления отглагольных существительных.

Только в Claude Code есть ещё агент-редактор (`agents/editor.md`) и команда `/pishi:redakt` (`commands/redakt.md`).
Codex читает тот же `.claude-plugin/marketplace.json`, отдельный манифест для него не нужен.
